## 1. Tujuan Milestone
Membangun master data hierarki organisasi tingkat atas (`Organization`), relasi hierarki Organisasi ke Outlet (1 organisasi menjalankan beberapa outlet, contoh: Seduhan Kopi Jodi dengan 1 manager menjalankan beberapa outlet, Kaveloka 1 outlet, Plaga 1 outlet), pengelolaan data outlet, grup outlet, penugasan pengguna dan Store Manager multi-outlet, serta pembagian kepemilikan/investor mitra (termasuk validasi pencegahan deaktivasi saat ada dokumen terbuka).
